# История семьи Раскольниковых

Презентация по литературе. Тема 7: история семьи Раскольниковых в романе
Ф. М. Достоевского «Преступление и наказание».

Десять слайдов: состав семьи, положение, быт, занятия, отношения с Родионом,
разрыв, судьба после преступления и вывод. HTML + CSS + JavaScript, без сборки
и без внешних библиотек.

## Как открыть

- двойной клик по `index.html`;
- или страница на GitHub Pages: `https://rootclean.github.io/lit/`.

Управление:

| Действие | Клавиши |
|---|---|
| Вперёд | `→`, `Space`, `PageDown` |
| Назад | `←`, `PageUp` |
| Первый / последний слайд | `Home` / `End` |
| Полный экран | `F` |
| Прямая ссылка на слайд | `index.html#5` |

Точки внизу слева и стрелки внизу по центру тоже кликабельны, на телефоне
работают свайпы.

## PDF

`Ctrl+P` → «Сохранить как PDF». Вёрстка уже настроена под 16:9
(13,33 × 7,5 дюйма), интерфейс и анимации при печати убираются.
Готовый файл лежит рядом: `presentation.pdf`.

## Титульный слайд

Первый слайд — только картинка, текста на нём нет. Сейчас там стоит фотография
Сенной площади (1900). Своё изображение положить в `img/title.jpg` — имя
обязательно такое, размер лучше от 1920 px по ширине. Если файла нет,
показывается заполнитель `img/title-placeholder.svg`.

## Текст и цитаты

Все цитаты дословные, часть и глава указаны рядом:

- письмо Пульхерии Александровны («ты один у нас, у меня и у Дуни...») — ч. 1, гл. 3;
- «Чем могла я с моими ста двадцатью рублями в год пенсиона помочь тебе?» — ч. 1, гл. 3;
- «Каморка его приходилась под самою кровлей...» — ч. 1, гл. 1;
- «Тяжело за двести рублей всю жизнь в гувернантках по губерниям шляться...» — ч. 1, гл. 4;
- «Не хочу я вашей жертвы, Дунечка, не хочу, мамаша!» — ч. 1, гл. 4;
- «...Оставьте меня! Оставьте меня одного!» — ч. 4, гл. 3;
- «— Родя, милый мой, первенец ты мой...» — ч. 6, гл. 7;
- смерть матери и брак Дуни — эпилог I.
