# Котики — небольшой трактат

Презентация на 7 слайдов: наука, анатомия, история, породы и факты о котиках.
HTML + CSS + JavaScript, без зависимостей и сборки.

## Запуск

Открыть `index.html` в браузере (двойной клик или перетащить в окно).

Управление:

| Действие | Клавиши |
|---|---|
| Вперёд | `→`, `Space`, `PageDown` |
| Назад | `←`, `PageUp` |
| Первый / последний слайд | `Home` / `End` |
| Полный экран | `F` |
| Прямая ссылка на слайд | `index.html#3` |

Точки внизу слева и стрелки внизу по центру тоже кликабельны; на телефоне работают свайпы.

На последнем слайде есть кнопка «Погладить кота» — маленькая пасхалка.

## PDF

`Ctrl+P` → «Сохранить как PDF». Вёрстка уже настроена под 16:9 (13.33 × 7.5 дюйма), интерфейс и анимации при печати убираются.

## Структура

```
index.html   — разметка семи слайдов
style.css    — оформление, адаптивность, печать
script.js    — навигация, точки, полный экран, пасхалка
img/         — title.jpg и slide-2…slide-7.jpg
```
